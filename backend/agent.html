Open browser views

Use Agent access → Share live view in the atlas to generate a read link. Paste that link into the chat. The sharing tab publishes its state, results, a canvas frame and recent numeric animation samples every five seconds. The read link expires after one hour; Stop sharing removes it immediately. Anyone with that link can inspect the shared model state. No account data, microphone or unrelated browser content is captured.

The backend cannot inspect an arbitrary open tab. atlas_view reports timestamps and freshness. Frames and results are supplied by the sharing browser. Browser tools can also call window.livingSystems.inspect(), window.livingSystems.trace() and window.AtlasAgent.frame() directly.

Experiment API

POST /api/experiment accepts JSON. Example: {"scene":"membrane","trace":"hh-2","time":0.06,"samples":true,"stride":10}. HH server traces are published reference runs; arbitrary conductance controls run in the browser. Recorded signals preserve pinned source provenance and units.
